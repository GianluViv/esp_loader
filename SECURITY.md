# Security Policy

## Supported versions

ESP Loader has no official release or supported stable version yet. Security fixes currently apply to the latest repository revision.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository if the **Report a vulnerability** option is available under the Security tab. If it is unavailable, open a minimal issue asking the maintainer for a private reporting channel, without including exploit details, private firmware, credentials, serial numbers, or sensitive logs.

Security reports are especially useful for issues involving:

- construction or execution of esptool commands;
- serial-device access and control;
- parsing of firmware manifests or partition tables;
- production ZIP extraction and path handling;
- file overwrite, unintended disclosure, or integrity verification.

Include the affected revision, operating system, reproduction conditions, likely impact, and a minimal safe proof of concept when possible. Allow the maintainer time to investigate and coordinate a fix before public disclosure.

This policy does not promise a response deadline while the project is pre-release.
